# Card game design

Owned by the TCG Design agent (`studio/roles/tcg.md`): what makes the card game fun and how it fits the RPG.

- `pillars.md` — what makes this card game fun; the test every card and mechanic must pass
- `elements.md` — each element's and confluence's identity and play pattern, and what's muddy
- `metrics.md` — the latest fun metrics (game length, choices, blowouts, Manifests) and how to reproduce them
- `progression.md` — card acquisition, collection, deckbuilding rules, loot cards by region
- `mechanics.md` — every keyword and mechanic, which elements use it, and why (to come)
- `bosses.md` — boss designs and the mechanics they introduce (to come)
- `tools/funmetrics.js` — plays AI-vs-AI games on an instrumented copy of `tools/engine.js` and reports the fun metrics
